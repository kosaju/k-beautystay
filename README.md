# K-BEAUTY STAY (k-beautystay.com)

부산·김해 체류형 K-뷰티 여행 안내 사이트. 운영 주식회사 창대한.

- 배포: Cloudflare Pages (Git 연동, main 브랜치 → 자동 배포, 빌드 없음, 출력 폴더 `/`)
- 언어: 日本語(기본) · English · 中文 · 한국어 — index.html 안 `T` 사전
- 법 준수: 외국인환자 유치업자 등록 전에는 의료기관 안내·예약을 열지 않는다(의료해외진출법 제6조·제28조). 등록 후 등록번호 표기와 함께 "제휴 의료기관"·4단계를 연다.
- 금지: 전후 사진, 최저가, 치료 효과 보장 문구, 미등록 의료기관 게재, 환자 개인정보 입력 칸(등록·처리방침 전)
